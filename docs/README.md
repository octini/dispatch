## What this package is

Planning package for Dispatch (Pi successor). Stage A records the frame only:
decisions, scope, manifest, evidence pointers. Feature specs come in Stage B.
Active seats are the Product Dispatch seats: Dispatcher
(plans/orchestrates; Beads lifecycle authority), Writer (sole agent editing
project artifacts), Seeker (research and documentation drafts; read-only on
project artifacts), Expert (independent review and complex-problem
consultation; read-only).
